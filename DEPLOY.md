# Размещение приложения

Приложение опубликовано 4 ноября 2026 года.

- Сайт: https://reshis-avia-ganin.onrender.com
- Репозиторий: https://github.com/AndreiGanin2910/reshis-avia-ganin
- Регион: Frankfurt. Python 3.12.11, FastAPI/uvicorn, PostgreSQL 18.
- Web service и база: Free. База истекает **4 декабря 2026 года**.
- Публичные регистрация, вход, расчёт, сохранение сессии после обновления страницы и выход проверены. Перезапуск web service отдельно не проверялся.

Ниже приведена инструкция повторного размещения. Фактически текущие сервис и база созданы через панель Render, DATABASE_URL задан в окружении; пароль базы в код не включён.

## Render: Python-сервис и PostgreSQL

Официальная инструкция: https://render.com/docs/deploy-fastapi
Справка Blueprint: https://render.com/docs/blueprint-spec
Ограничения бесплатных ресурсов: https://render.com/docs/free

1. Опубликовать содержимое этой папки в отдельном репозитории GitHub. Не включать .venv, var, базы SQLite, .env и реальные учётные данные. В корне репозитория должны находиться app.py, auth.py, index.html, requirements.txt и render.yaml.
2. В своём Render выбрать создание Blueprint из этого репозитория. Подготовленный render.yaml описывает один Python web service и одну PostgreSQL.
3. Перед созданием проверить планы обоих ресурсов. В файле явно указано plan: free. Не соглашаться на платный вариант без собственного решения.
4. DATABASE_URL должен ссылаться на созданную PostgreSQL. COOKIE_SECURE должен равняться 1. Оба параметра предусмотрены в Blueprint.
5. Дождаться успешной сборки и статуса сервиса. Проверить /healthz по HTTPS: должен вернуться status=ok.
6. Открыть публичный URL в отдельном браузере или инкогнито, зарегистрировать учебный аккаунт, проверить вход, расчёт, выход и повторный вход.
7. После перезапуска сервиса убедиться, что аккаунт сохранился. Этот пункт полезен для дополнительной проверки устойчивости хранения после нового развёртывания.

Бесплатный web service засыпает после 15 минут без запросов. Первый запрос после простоя может занять около минуты. Бесплатная PostgreSQL Render истекает через 30 дней. Учитывайте дату проверки жюри: для более долгого хранения требуется другой тариф или другая постоянная PostgreSQL. Пока сама база доступна, перезапуск web service не удаляет аккаунты.

## Другой Python-хостинг или VPS

Используйте Dockerfile или обычный запуск uvicorn. Подключите постоянную PostgreSQL через DATABASE_URL или постоянный том /app/var для SQLite, если запускается ровно один экземпляр приложения. Установите COOKIE_SECURE=1 за HTTPS. Обычный PHP-хостинг и статический GitHub Pages не запускают FastAPI.

Не публикуйте базу пользователей вместе с кодом. Не выдавайте временный туннель с локального компьютера за постоянный хостинг.
